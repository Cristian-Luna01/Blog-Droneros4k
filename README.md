# Droneros 4K

Blog sobre experiencias de vuelo, tecnología, mantenimiento y hardware de drones. Proyecto de formación en **Generation México** con HTML, CSS y JavaScript.

[Ver sitio web](https://droneros4k.netlify.app/) · [Perfil profesional](https://www.linkedin.com/in/cristianhern%C3%A1ndezluna/)

## Ejecutar en local

```bash
git clone https://github.com/Cristian-Luna01/Blog-Droneros4k.git
cd Blog-Droneros4k
```

Abre `index.html` en un navegador moderno o sirve la carpeta con un servidor estático como Live Server de VS Code. Esta versión no incluye un paso de compilación ni un gestor de paquetes.

## Revisar cambios

Comprueba la navegación entre las páginas, la visualización de imágenes y la presentación en móvil y escritorio. Conserva las rutas y las mayúsculas de nombres como `Pic/` al publicar. No se afirma que una página de contacto implemente por sí sola un servicio de envío de mensajes.
