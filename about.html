Desarrollo & Vuelo

Hola, soy Cristian. Fusiono el desarrollo de software con la pasión por la tecnología aeroespacial civil.

Este proyecto inició como un requerimiento para adentrarme en el desarrollo web, pero rápidamente evolucionó hacia una bitácora personal formal. Aquí documento de manera técnica las soluciones prácticas, la gestión de hardware y las experiencias de vuelo que los manuales convencionales suelen omitir.

Mi objetivo es construir una base de conocimientos sólida para pilotos emergentes: desde entender la diferencia entre fotogrametría y vuelo recreativo, hasta optimizar bancos de baterías para expediciones en la naturaleza.
